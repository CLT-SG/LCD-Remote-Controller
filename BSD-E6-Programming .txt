Example: Setting Brightness to 100
To set brightness to 100, use the following command:
B2 00 00 3A 01 41 64 1E
The last hex value (1E in this case) must be calculated using an XOR operation.

How to Calculate the Last Hex (Checksum)
The XOR calculation starts from 0x3A and includes all values up to the brightness value.
_____________________________________________________________________________________
Method 1: Using Windows Calculator
1. Open the Windows Calculator.
2. Switch to Programmer Mode (Alt + 3).
3. Set the calculator to Hex mode.
4. Perform the XOR operation in the following order:
3A XOR 01 XOR 41 XOR (Brightness value)
5. The result will be the final checksum value.
_____________________________________________________________________________________
Method 2: Using an Online XOR Calculator
1. Open the XOR calculator: https://toolslick.com/math/bitwise/xor-calculator
2. Insert the hex values in this format:
3A 01 41 (Brightness value)
3. Click Calculate and copy the hex result at the bottom.
4. Use the result as the last hex in your command.

For Brightness = 100 (0x64), the XOR calculation would be:
3A 01 41 64 XOR ? 1E

So the complete command is:
B2 00 00 3A 01 41 64 1E
